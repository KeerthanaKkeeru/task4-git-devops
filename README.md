# Task 4: Version-Controlled DevOps Project with Git

## Project Overview
This project demonstrates Git version control and GitHub collaboration practices used in DevOps.

## Objectives
- Initialize a Git repository.
- Create and manage main, dev, and feature branches.
- Track changes using meaningful commits.
- Create and merge pull requests.
- Use README.md, .gitignore, and Git tags.
- Document project activities using Markdown.

## Tools Used
- Git
- GitHub
- Visual Studio Code
- Windows PowerShell

## Branching Strategy
- main: Stable project version.
- dev: Integration and development branch.
- feature: New feature development.

## Project Workflow
1. Initialize the local Git repository.
2. Create the initial commit.
3. Push the project to GitHub.
4. Create dev and feature branches.
5. Make changes and commit them.
6. Create pull requests and merge changes.
7. Create a version tag.
8. Verify the repository and commit history.

## Deliverables
A GitHub repository containing project documentation, branches, commits, a .gitignore file, and a version tag.
